# S-02 failures (append-only)

Dead ends and misses, in the order they happened. Date 2026-11-22.

1. **`K71.small-population/symmetric-transient` first verdict: `error`.** The encoding assumed the S-fixed states of the lumped chain are the empty state and the full state. Relabeling also fixes the multisets `(empty, empty, F)`, `(empty, F, F)`, `(one agent per single form)` and `(one agent per pair of forms)`, because the chain forgets which agent holds which inventory. The check raised on an unexpected fixed state. The expectation was wrong, not the chain. The check now searches all six S-fixed multisets, and gauge.md Part B corrects the wording in Part A. No `expect` changed.
2. **Vacuous-pass hazard in `witness.verdict`, caught before the first run.** A witness whose hypothesis comes out false returns `no-counterexample`, so an `expect: no-counterexample` check passes if its own precondition fails. The first draft of `gauge.py` returned computed booleans as hypotheses in several exhaustive checks (Aut(D) = D_N, S = Stab, absorbing set, S-fixed transience). Those would have passed silently on a wrong encoding. Rewritten so every hypothesis dict holds constant `True`, a violation moves the gap above tolerance, and a failed precondition raises. The tool itself is unchanged and still has the hazard for other modules.
3. **No `V3` in the tier derivation.** `check.tiers` returns V0, V4 or R. The charter's acceptance tier cannot appear in `claims.md` however many checks pass. Not worked around: no `proves` check was put on a bare claim id to force a tier, because the dependencies K60 to K64 are definitions with no checks and would cap it at V0, and because a finite instance does not prove the universal statement. The finite checks sit on narrowed subjects instead.
4. **No simulation kind in `check.py`.** Statistical checks run as `witness` probes with the gap carrying the margin to a pre-registered threshold. A `simulation` kind would need a sanity check and a case in `test_gates.py`, which is outside this charter.
