# Notation table (F-00)

*One meaning per symbol. Later rungs use these symbols and no others for these objects. Source key: GM = `explorations/grounded-misprision-program.md`; outline = `explorations/symmetry-platonic-program.md`; spine = `program/spine.md`; plan = `program/formalization.md`. Claim labels (T1, C13, S4, K20, R2, X9) are labels, not symbols.*

## Rules used to resolve clashes

1. GM's symbols keep their GM meaning (GM is the parent program). Where GM clashes with itself, the object with more uses keeps the symbol.
2. The outline's renames (reading $\rho_l\to r_l$, quantizer $q_a$, blur $\nu_a$, representations $X_a$, word family $\mathcal S$, irreps $\rho$) stay.
3. Spine, then plan, uses are renamed when they clash. When a newer object is the same object as an older one, it reuses the older symbol (stated in "Replaces").
4. Letters are scarce, so new names are subscripted or set in roman type ($\mathrm{Arc}_t$, $\mathrm{refl}$). Roman multi-letter symbols are single symbols, not products.
5. Only `\varphi`, `\varepsilon`, `\vartheta` are used (never `\phi`, `\epsilon`).
6. A subscript that indexes an agent, time or irrep ($a$, $t$, $\rho$) is not a new symbol; $\theta$ covers $\theta_a$ and $\theta_t$.

## Visually close (kept, with the rule that keeps them safe)

- $G$ (group) and $\mathcal G$ (grounded information): both are GM's, so neither can be renamed. Always typeset the group as plain italic $G$ and grounded information as calligraphic $\mathcal G$ or $\mathcal G_t$. Never write $\mathcal G$ for a group. The plan's third member $\mathsf G_a$ is gone ($\mathrm{Gram}_a$).
- $q$ (machine reader) and $q_a$ (quantizer): bare $q$ is always the machine reader's distribution; $q_a$ always maps observations to classes. Where a machine is also an agent, write $q$ for its reader and $q_a$ only for its classes.
- $\theta$, $\Theta_t$ and $\vartheta$: $\theta$ is parameters, $\Theta_t$ the same as a random variable, $\vartheta$ appears only inside the S30 closure formulas.
